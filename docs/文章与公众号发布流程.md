# 一份母稿，两端发布

网站文章保存在 `src/content/blog/`，案例和课程分别保存在 `src/content/cases/` 与 `src/content/courses/`。每篇 Markdown 都有独立地址，支持文章目录、分类、RSS 与搜索引擎索引。

1. 复制 `templates/新文章.md` 到文章目录，使用简短英文文件名作为永久链接。
2. 默认 `draft: true`。核对标题、摘要、正文与来源；案例还需要 `publicApproved: true` 才会公开。
3. 本地预览检查内容与手机排版，确认后填写发布日期并改为 `draft: false`。未来日期文章不会进入当前构建。
4. 将同一母稿整理到“心启花开”公众号编辑器，检查公众号排版后发布。
5. 公众号发布后，将真实链接填入 `wechatUrl`。两端逐项核对完毕才设 `syncStatus: synced`；节选或修改版使用 `needs-review` 并在 `note` 说明版本关系。
6. 提交内容更新，Cloudflare 接入仓库自动构建后会发布网站。未来定时稿需在到期时触发构建，不能只依靠静态站等待日期。

`.pages.yml` 已提供文章与课程编辑表单，可通过 Pages CMS 连接 GitHub 仓库后使用。此配置不代表账号已连接。公众号目前使用人工发布，未接入微信自动发布 API。

课程主题 `theme` 不需要活动时间。发布真实活动时必须填写有时区的开始、结束时间，如 `2026-11-01T19:30:00+08:00`，同时核实形式、地点、价格和报名边界。

本次首篇演练为《从教育者到赋能者：我的十年觉醒进化之路》。内容从知识库原文整理为节选，保留 Amy 提供的真实公众号链接，不标记为全文同步。
