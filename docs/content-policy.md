# 内容与设计说明

## 主线

人物主张 → 家庭日常共鸣 → RISE 理解 → 个人观点 → 案例 → 人物经历 → 课程 → 服务选择 → 笔记 → 联系。

RISE 采用有明确确认台账的 2026-09-23 口径：E 情绪/鼓励与成长环境、S 学习策略、I 内驱力、R 心理韧性；判断顺序 E → S → I → R → 成绩。字母组成不是实施次序。四维相互支持，E 贯穿全程。成绩用于观察和反馈。研究支持具体构念，不宣称已验证 RISE 整体效果。

## 已使用的知识来源类别

- 个人观点：Amy 的教练定位与工作逻辑、双轨协作观点。
- 理论与课程主题：学业卡点课程 v9 中的确认台账和主题母稿。
- 案例：持续陪伴过程中的自我评价、复习优先级选择、环境与学习理解的阶段记录。
- 视觉：Amy 知识库中的本人肖像和现有品牌莲花标记。图片已压缩，公开文件不包含原始 EXIF。

不把未经核实的总体统计、具体分数、机构认证或服务人数放到网站上。人物经历仅采用来源已记录的工作领域，不发布数量或资质效果主张。
